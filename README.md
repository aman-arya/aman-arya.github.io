# aman-arya.github.io

Personal academic website for Aman Kumar, built with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — home, bio, education, research interests, news
- `publications.html` — publications and research projects
- `teaching.html` — teaching experience
- `awards.html` — awards and honors
- `contact.html` — contact details

Shared assets: `styles.css`, `script.js`, plus images and the CV PDF.

## Running locally

Just open `index.html` in a browser, or serve the folder with any static server, e.g.:

```
python -m http.server
```

## Deployment

Hosted on GitHub Pages from the `main` branch. Pushing to `main` updates the live site.
